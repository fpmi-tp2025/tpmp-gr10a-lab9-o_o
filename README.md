# MobileBankApp  
**Проект мобильного приложения для банка**, реализующий авторизацию, просмотр счетов, курсы валют и поиск отделений.  

## Описание  
Приложение позволяет клиентам:  
- Авторизоваться через логин/пароль.  
- Просматривать активные и заблокированные счета (текущий, сберегательный, кредитный, карт-счет).  
- Получать информацию о курсах валют.  
- Находить ближайшие отделения банка с помощью геолокации.  

## Установка  
1. Клонируйте репозиторий: `git clone https://github.com/fpmi-tp2025/tpmp-gr10a-lab9-o_o.git `.   
2. Откройте файл `MobileBankApp.xcworkspace` в Xcode.  
3. Запустите приложение на симуляторе или устройстве.  

## Использование  
1. Введите логин/пароль для входа.  
2. В меню выберите "Просмотр счетов" или "Курсы валют".  
3. На карте отобразятся отделения банка.
