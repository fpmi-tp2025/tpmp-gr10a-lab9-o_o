# Функциональные требования  
## Таблица требований  
| ID | Требование | Описание |  
|----|------------|----------|  
| F1 | Авторизация | Пользователь вводит логин/пароль для входа. |  
| F2 | Просмотр счетов | Отображаются только активные и заблокированные счета. |  
| F3 | Типы счетов | Поддерживаемые типы: текущий, сберегательный, кредитный, карт-счет. |  
| F4 | Курсы валют | Пользователь может просматривать актуальные курсы. |  
| F5 | Карта отделений | Отображение филиалов банка с поиском ближайшего отделения. |  

## Диаграмма Use Case   
**Сценарии:**  
- **Авторизация**: Пользователь вводит логин/пароль.  
- **Поиск отделений**: Приложение запрашивает геолокацию, отображает филиалы на карте.
