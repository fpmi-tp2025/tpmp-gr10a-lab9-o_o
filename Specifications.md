### Спецификация требований для мобильного приложения банка

---

#### **1. Назначение приложения/системы**  
Мобильное приложение банка предназначено для предоставления клиентам возможности управлять своими банковскими счетами, отслеживать курсы валют и находить ближайшие отделения банка. Основные функции:
- Авторизация и аутентификация пользователей.
- Просмотр активных и заблокированных счетов.
- Отображение информации о типах счетов (текущий, сберегательный, кредитный, карт-счет).
- Поддержка овердрафта для зарплатных счетов.
- Отображение курсов валют.
- Поиск ближайших отделений банка с помощью геолокации.

---

#### **2. Общее описание**  
**Пользователи:**  
- **Клиент банка**: авторизуется, просматривает счета, курсы валют, ищет отделения.  
- **Администратор** (необязательно): управляет данными о счетах, курсах валют и отделениях.  

**Требования к программному обеспечению:**  
- Операционная система: iOS 14+.  
- Язык разработки: Swift.  
- Библиотеки: UIKit или SwiftUI для интерфейса, SQLite для хранения данных, CoreLocation для геолокации.  
- Хранение данных: локальное (UserDefaults или plist) для кэширования настроек пользователя, SQLite для хранения счетов, курсов валют и информации об отделениях.  

**Требования к аппаратному обеспечению:**  
- Устройства: iPhone/iPad.  
- Датчики: GPS для определения местоположения.  
- Камера (опционально): для сканирования документов.  

---

#### **3. Спецификация требований**  
##### **3.1 Функциональные требования**  
| ID | Требование | Описание |  
|----|------------|----------|  
| F1 | Авторизация | Пользователь вводит логин/пароль для входа в приложение. |  
| F2 | Просмотр счетов | Отображаются только активные и заблокированные счета (закрытые счета скрыты). |  
| F3 | Детали счета | Для каждого счета отображаются: номер, тип, баланс, статус, дата открытия. |  
| F4 | Типы счетов | Поддерживаемые типы: текущий, сберегательный, кредитный, карт-счет. |  
| F5 | Карт-счет | Поддерживает подтипы: зарплатный, сберегательный, кредитный. |  
| F6 | Овердрафт | Для зарплатных счетов доступна функция овердрафта. |  
| F7 | Курсы валют | Пользователь может просматривать актуальные курсы валют. |  
| F8 | Карта отделений | Отображение филиалов банка на карте с возможностью поиска ближайшего отделения. |  
| F9 | Геолокация | Приложение автоматически определяет местоположение пользователя для поиска отделений. |  

##### **3.2 Удобство использования**  
- **Интерфейс**: интуитивно понятный дизайн, соответствующий Apple HIG.  
- **Локализация**: поддержка английского, русского и одного дополнительного языка (например, белорусского).  
- **Навигация**: простой переход между экранами через меню.  

##### **3.3 Требования надежности**  
- **Безопасность**: шифрование чувствительных данных (логин/пароль) в UserDefaults.  
- **Обработка ошибок**: корректное отображение ошибок (например, неверный пароль, отсутствие интернета).  
- **Восстановление данных**: сохранение состояния приложения при перезапуске.  

##### **3.4 Требования производительности**  
- **Время загрузки**: экраны должны загружаться за ≤2 секунды.  
- **Отзывчивость**: реакция на действия пользователя — ≤0.5 секунды.  
- **Энергопотребление**: оптимизация использования GPS и сетевых запросов.

#### **4. Диаграммы**  
##### **4.1 Диаграмма вариантов использования (Use Case)**  
```plaintext
[Пользователь] 
  └──> [Авторизация]
  └──> [Просмотр счетов]
       └──> [Выбор счета]
       └──> [Просмотр деталей счета]
  └──> [Просмотр курсов валют]
  └──> [Поиск отделений]
       └──> [Отображение на карте]
       └──> [Поиск ближайшего отделения]
```
**Сценарии:**  
- **Авторизация**: Пользователь вводит логин/пароль. При успешной авторизации открывается главное меню.  
- **Поиск отделений**: Приложение запрашивает геолокацию, отображает филиалы на карте.

##### **4.3 Физическая модель базы данных (SQLite)**  
```sql
-- Пользователи
CREATE TABLE Users (
    id INTEGER PRIMARY KEY,
    login TEXT UNIQUE NOT NULL,
    password TEXT NOT NULL
);

-- Счета
CREATE TABLE Accounts (
    id INTEGER PRIMARY KEY,
    user_id INTEGER,
    type TEXT CHECK(type IN ('current', 'savings', 'credit', 'card')),
    subtype TEXT CHECK(subtype IN ('salary', 'savings', 'credit')),
    balance REAL,
    status TEXT CHECK(status IN ('active', 'blocked')),
    overdraft BOOLEAN DEFAULT FALSE,
    FOREIGN KEY(user_id) REFERENCES Users(id)
);

-- Курсы валют
CREATE TABLE CurrencyRates (
    currency TEXT PRIMARY KEY,
    rate REAL
);

-- Отделения
CREATE TABLE Branches (
    id INTEGER PRIMARY KEY,
    name TEXT,
    latitude REAL,
    longitude REAL
);
```
